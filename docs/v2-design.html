Claude + Codex 사용량, 어느 기기에서 쓰든 맥 메뉴바에

v0.1은 맥의 로컬 Codex 로그만 읽어서 아이폰·웹 사용량을 볼 수 없었습니다. v2는 각 서비스에 계정 전체 사용량을 직접 물어보고, 값이 얼마나 최신인지를 화면에 그대로 드러냅니다.

Thu 20:14
표시 모드

슬라이더로 시간을 흘려 보세요. 폴링이 정상이면 5h, 몇 분 밀리면 ~5h, 15분이 넘으면 회색이 됩니다. 남은 10% 이하 노랑, 5% 이하 빨강 기준은 v0.1과 같습니다.

모든 소스는 결국 서버가 계산한 값을 전달합니다. 그래서 여러 소스가 있으면 가장 최근에 관측된 값을 씁니다. 동시에 관측됐다면 계정에 직접 물어본 값이 우선입니다.

UsageCore

모델 · 파서 · 정책

  • 공통 UsageSnapshot / UsageWindow
  • app-server, OAuth usage, statusline, 세션 로그 파서
  • Freshness live / recent / stale
  • PollPolicy 적응형 주기와 backoff
UsageProviders

실제 연결

  • CodexAppServerClient: stdio JSON-RPC, 20초 timeout, 죽으면 재시작
  • ClaudeCredentialStore: /usr/bin/security로 읽기 전용
  • StatuslineBridge: 설치 전 settings 백업, 해제 시 복원
Howmuchusage.app

메뉴바 앱

  • provider별 폴링 루프 + 깨우기 트리거
  • 원래 2줄 battery 블록을 provider마다
  • popover: 상태 · 소스 · 다음 조회 · 연결 버튼
